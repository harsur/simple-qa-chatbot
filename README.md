# Simple Q&A Chatbot with Python

## Project Description
CampusHelper is a simple rule-based chatbot developed using Python. It responds to greetings and provides a basic response to other messages.

## Features
- Responds to greetings such as "Hello" and "Good morning".
- Prompts the user when an empty message is entered.
- Ends the conversation when the user types "quit", "exit", or "bye".

## Technologies Used
- Python
- Basic conditional statements
- While loop and user input

## How to Run
1. Install Python 3.
2. Open Command Prompt in the folder containing `chatbot.py`.
3. Run the command:

   `python chatbot.py`

4. Type a message and press Enter.
5. Type `quit` to exit.

## Sample Output
```text
CampusHelper: Hello! Ask me something, or type 'quit' to stop.
You: Good Morning!
CampusHelper: Hello! How can I help you?
You: quit
CampusHelper: Goodbye!
```
